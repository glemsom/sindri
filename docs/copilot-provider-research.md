# GitHub Copilot as an agent-app provider

*Checked 2026-02-24. Primary-source scope: GitHub's official Copilot SDK repository and GitHub Docs.*

## Confirmed

- **Recommended integration:** GitHub publishes the Copilot SDK (TypeScript, Python, Go, .NET, Java, Rust). It embeds Copilot CLI's agent runtime; the SDK communicates with it over JSON-RPC, by default through a CLI child process. This is an agent runtime integration, not documented as a general-purpose hosted LLM REST endpoint. [SDK README](https://github.com/github/copilot-sdk/blob/main/README.md)
- **Access/authentication:** The SDK documents CLI signed-in credentials, OAuth user tokens, environment tokens, organization server-to-server tokens, and BYOK provider keys. Interactive user/OAuth/environment methods require an eligible Copilot subscription; organization installation-token/GitHub Actions use requires organization policy; BYOK requires no Copilot login. [Authentication guide](https://github.com/github/copilot-sdk/blob/main/docs/auth/authenticate.md) · [server-to-server](https://github.com/github/copilot-sdk/blob/main/docs/auth/server-to-server-tokens.md) · [BYOK](https://github.com/github/copilot-sdk/blob/main/docs/auth/byok.md)
- **Endpoints/models:** BYOK configures provider base URL, API key, model name, and wire protocol; supported types include OpenAI-compatible endpoints, Azure/Foundry, Anthropic, Ollama and other compatible servers. The SDK docs distinguish Responses and Completions wire APIs. GitHub does not specify a single public Copilot inference URL in this SDK setup. [BYOK guide](https://github.com/github/copilot-sdk/blob/main/docs/auth/byok.md)
- **Tools/streaming:** SDK sessions expose custom tools, permission handling, and event-driven assistant output. Models used with Copilot CLI must support tool/function calling and streaming; this is a model capability requirement, not evidence that every provider API has a uniform GitHub endpoint. [SDK README](https://github.com/github/copilot-sdk/blob/main/README.md) · [Copilot CLI docs](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-cli)
- **Consumer token:** A consumer Copilot subscription can authorize the SDK via supported GitHub login/token methods, subject to plan, usage allowance, and policy. That does **not** make a consumer subscription token a reusable arbitrary LLM-provider API key or authorize scraping/private endpoints. Use the SDK/runtime or documented BYOK path. SDK usage consumes Copilot allowance/credits. [Authentication guide](https://github.com/github/copilot-sdk/blob/main/docs/auth/authenticate.md) · [CLI billing docs](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-cli)
- **Terms/product constraints:** Use supported documented SDK/auth flows and comply with GitHub terms and plan/org policies. The SDK README describes usage billing like Copilot CLI. [SDK README](https://github.com/github/copilot-sdk/blob/main/README.md) · [GitHub Terms](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service)

## Uncertainty / boundary

GitHub's public docs establish SDK support and supported authentication, but do not promise a stable direct Copilot inference API endpoint for arbitrary agent frameworks, nor that consumer tokens can be extracted or presented to third-party OpenAI-compatible clients. A token accepted by the SDK is authorization for that product flow, not a general API contract. Verify current plan eligibility, model availability, and organization policy before deployment.
